# IWAE 자주 묻는 질문

[English](FAQ.md)

처음 쓰는 분들이 가장 많이 묻는 것을 짧게 답했습니다. 여기 없는 것은 [Discussions](https://github.com/radic2682/IWAE/discussions)에 물어보시거나 [이슈](https://github.com/radic2682/IWAE/issues/new/choose)를 열어 주세요.

## 기본

**IWAE 가 무엇인가요?**
PDF 에 형광펜을 칠하면 그 문장과 메모가 이어져 남는 데스크톱 PDF 리더입니다(Windows·macOS). 나중에 메모를 누르면 PDF 가 그 문장으로 돌아갑니다. Markdown 파일도 같은 방식으로 쓰고, 노트 하나에 여러 문서의 메모를 모을 수 있습니다.

**무료인가요? 라이선스는요?**
네. MIT 라이선스의 오픈 소스입니다([LICENSE](../LICENSE)). 함께 들어 있는 외부 구성 요소와 글꼴은 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)에 적혀 있습니다.

**어떤 운영체제에서 되나요?**
Windows 10/11(x64)과 macOS 12 이상입니다. Linux 는 아직 지원하지 않습니다. macOS 빌드는 Windows 빌드와 따로 만들어서, 한동안 Windows 용만 올라오는 버전이 있을 수 있습니다.

**안정적인가요?**
알파 단계입니다. 읽기·메모·노트·저장은 잘 되고 저장은 저널을 쓰는 원자적 방식이지만, 버전이 바뀌면서 화면과 파일 형식이 달라질 수 있습니다. 설정의 Vault 자동 백업을 켜 두고, 업데이트 전에 릴리스 노트를 읽어 주세요.

## 내 파일과 개인정보

**Vault 가 무엇인가요?**
IWAE 에서 연 폴더입니다. 그 안의 PDF·Markdown 이 디스크에 있는 모습 그대로 보이고, IWAE 가 옮기거나 잠그지 않습니다. 노트는 `*.iwnote` 파일(기본은 `노트` 폴더)로 저장되고, 그 밖에 IWAE 가 필요한 것(형광펜, 책갈피, 검색 색인, 번역 캐시, 기록, 휴지통)은 Vault 안의 숨은 `.iwae` 폴더에 있습니다.

**내 PDF 파일이 바뀌나요?**
읽거나 형광펜을 칠하거나 메모를 쓸 때는 바뀌지 않습니다. 그것들은 `.iwae` 에 따로 저장됩니다. PDF 를 직접 고치는 도구(쪽 편집, 가리기, 압축 등)를 쓸 때만 파일이 다시 쓰입니다. 쪽 편집은 원본을 먼저 백업하고, 대부분의 도구는 복사본으로 저장할 수도 있습니다.

**Dropbox·OneDrive·iCloud 로 동기화해도 되나요?**
됩니다. 평범한 폴더이기 때문입니다. 두 창에서 바꾼 것은 합쳐지고, 두 컴퓨터에서 동시에 고친 충돌은 덮어쓰지 않고 나란히 남깁니다. 같은 Vault 를 두 컴퓨터에서 정확히 같은 시간에 열어 두는 것은 피해 주세요.

**내 컴퓨터 밖으로 나가는 것이 있나요?**
직접 켠 것만 나갑니다.

- 클라우드 번역 제공자(OpenAI, Anthropic, Gemini, Azure Translator, DeepL)를 골랐을 때, 번역하려고 선택한 글. Ollama 로컬 번역은 컴퓨터 밖으로 나가지 않습니다.
- 릴리스 빌드의 업데이트 확인.
- 설정에서 로컬 MCP 서버를 켠 경우에만, 외부 AI 에이전트의 요청. 기본은 꺼져 있고 `127.0.0.1` 에서만 받습니다.

계정, 원격 측정, 사용 통계는 없습니다. OCR 은 컴퓨터 안에서 돕니다.

**클라우드 번역 API key 는 어디에 저장되나요?**
Vault 나 프로젝트 파일이 아니라 운영체제의 자격 증명 저장소(Windows 자격 증명 관리자, macOS 키체인)에 저장됩니다.

**Vault 를 백업하려면요?**
설정에 Vault 전체 백업(zip)과 자동 백업 주기, 빈 폴더로의 복원이 있습니다. 폴더를 그냥 복사해도 됩니다.

**실수로 지웠어요.**
지운 파일은 먼저 Vault 휴지통으로 가고, 노트와 주석의 이전 상태도 한동안 남습니다. 바로 `Ctrl+Z` 로 되돌리거나 휴지통을 보세요.

## 쓰는 법

**내 파일 없이 먼저 써 보려면요?**
처음 켤 때 **예시로 시작**을 고르면 「IWAE 사용 설명서」 튜토리얼 PDF 가 든 예시 Vault 가 만들어집니다.

**기본 PDF 앱으로 쓸 수 있나요?**
네. Windows 의 「기본 앱」(앱 안에 그 화면으로 가는 바로가기가 있습니다)이나 macOS 의 「다음으로 열기」에서 IWAE 를 고르세요. Vault 밖의 PDF 는 Vault 로 복사해 넣을 수 있습니다.

**스캔한 PDF 라서 글자를 고르거나 검색할 수 없어요.**
왼쪽 바 PDF 도구의 OCR 로 글자 층을 더하세요. OCR 은 함께 들어 있는 PaddleOCR 모델로 컴퓨터 안에서 돌고, 품질이 낮은 스캔에서는 완벽하지 않습니다.

**암호가 걸린 PDF 예요.**
열 때 암호를 물어봅니다. 「암호 푼 복사본」 도구로 암호 없는 복사본을 저장할 수도 있습니다.

**아주 큰 PDF 가 느려요.**
큰 파일의 성능 개선이 진행 중입니다([로드맵](ROADMAP.md)). 특정 파일이 느리면 파일 자체가 아니라 쪽 수와 파일 크기를 적어 버그 제보를 열어 주세요.

**번역은 어떻게 하나요?**
글을 고르고 번역을 누르면 결과가 옆에 나타나며 원문을 바꾸지 않습니다. Ollama 로컬 모델이나 내 API key 로 쓰는 클라우드 제공자를 고르세요(설정 → 번역). 같은 번역은 Vault 에 캐시됩니다.

**AI 가 내 노트를 읽나요?**
IWAE 에는 채팅이 없습니다. MCP 서버를 켜면 Claude Code 같은, 직접 연결한 외부 에이전트가 Vault 를 검색하고 쪽을 읽고 메모를 더할 수 있습니다. PDF 파일은 고치지 못합니다. README 의 「Working with AI agents」를 보세요.

**단축키는 어디서 보나요?**
설정 → 단축키·마우스, 그리고 README 의 표입니다. `Ctrl+Shift+P` 는 명령 팔레트입니다.

## 문제 해결

**설치 파일을 실행하면 「Windows 의 PC 보호」(SmartScreen)가 떠요.**
릴리스 설치 파일에 아직 코드 서명이 없어서 SmartScreen 이 알려지지 않은 앱이라고 경고합니다. 이 저장소의 Releases 페이지에서 받은 파일이 맞을 때만 「추가 정보」 → 「실행」을 누르세요. 코드 서명은 준비 중입니다([CODE_SIGNING.md](CODE_SIGNING.md)).

**macOS 가 개발자를 확인할 수 없어 열 수 없다고 해요.**
아직 공증(notarization)을 하지 않았습니다. 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 한 번 누르세요.

**Windows 에서 창이 비어 있거나 PDF 가 안 그려져요.**
Microsoft Edge WebView2(최신 Windows 10/11 에는 들어 있습니다)와 실행 파일 옆의 `pdfium.dll` 이 필요합니다. 설치용 `.exe` 로 다시 설치해 보세요. 백신이 `pdfium.dll` 을 격리한 경우가 알려진 원인입니다.

**Markdown → PDF 가 실패해요.**
Markdown 화면은 Microsoft Edge 나 Google Chrome 으로 그립니다. 둘 중 하나를 설치하세요.

**PowerPoint 가 없다고 나와요.**
`.ppt`/`.pptx` 변환은 같은 Windows PC 에 깔린 PowerPoint 를 씁니다. 다른 곳에서 PDF 로 바꿔 넣어 주세요.

**문제는 어떻게 보고하나요?**
앱에 「문제 보고」 명령이 생기면 그것을 쓰세요. 버전, 시스템 정보, 최근 기록을 문서 내용 없이 모아 주고, 보내기 전에 내용을 직접 확인할 수 있습니다. 그다음 [버그 제보](https://github.com/radic2682/IWAE/issues/new?template=bug_report.yml)를 열어 주세요. 첨부물에서 개인 문서 내용은 지워 주세요.

**보안 문제를 찾았어요.**
공개 이슈로 올리지 마시고 [SECURITY.md](../SECURITY.md)를 따라 주세요.

## 기여

**어떻게 도울 수 있나요?**
재현 방법이 적힌 버그 제보, 번역, 범위가 좁은 풀 리퀘스트를 환영합니다. 먼저 [CONTRIBUTING.md](../CONTRIBUTING.md)를 읽어 주세요. 큰 아이디어는 코드를 쓰기 전에 Discussions 에서 방향을 맞춰 보세요.

**X 기능이 들어오나요?**
[로드맵](ROADMAP.md)을 보세요. 계획된 것과 아이디어일 뿐인 것을 나눠 적었습니다. IWAE 는 로컬 우선이라 서버나 계정이 필요한 기능은 들어오기 어렵습니다.
