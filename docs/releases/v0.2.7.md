# IWAE v0.2.7

Text, HTML and XML documents, and a new setup window.

## New

- IWAE now opens TXT, HTML and XML files as documents, next to PDF and Markdown. HTML opens in a clean reader view and XML is shown as readable text. You can highlight them, memo them and search them like any other document.
- Files in older encodings such as CP949 and UTF-16 are detected and shown correctly.
- Add documents from a file picker or by dropping them in. A file that is already inside the vault opens in place instead of being added twice.
- The Windows installer is now a single small window with one button instead of a multi-page wizard. It shows Update or Reinstall when IWAE is already installed, and you can still change the install location before installing.
- If IWAE is open, the setup window asks before closing it, so you can save first.
- In-app updates use the same window: it shows the progress, then reopens IWAE.
- Uninstalling from Windows Settings opens the same window. Your vaults and settings stay.

## Changed

- Selecting text no longer opens a note on its own. If no note is visible, IWAE tells you how to open one, and your selection stays.
- When an import fails, the message names the file and says why.

## Fixed

- Local images in documents can only load from the vault or the document's folder. Network-share, other-drive and app-internal image references are blocked and shown as a placeholder.
- Very large HTML files (over 5 MB) open as plain text with a notice instead of slowing the app down.
- Highlights in text documents stay in place when the document is re-rendered.

## Notes

- The MSI installer is unchanged.
- Silent installs (`/S`, `/D=`) work as before.
