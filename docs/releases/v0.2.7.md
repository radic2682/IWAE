# IWAE v0.2.7

A new setup window.

## New

- The Windows installer is now a single small window with one button instead of a multi-page wizard. It shows Update or Reinstall when IWAE is already installed, and you can still change the install location before installing.
- If IWAE is open, the setup window asks before closing it, so you can save first.
- In-app updates use the same window: it shows the progress, then reopens IWAE.
- Uninstalling from Windows Settings opens the same window. Your vaults and settings stay.

## Notes

- The MSI installer is unchanged.
- Silent installs (`/S`, `/D=`) work as before.
