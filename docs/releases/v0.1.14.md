# IWAE v0.1.14

Safer deleting, one place for notifications, and layout fixes.

## Changed

- **Moving a document to the trash now asks first.** Right-click → "Move to trash…" shows the document name and location, and focus starts on Cancel. Folder trash lists the documents it contains (up to six names plus a count). Every trash entry now records which action moved it there, and restoring a folder from the trash is more robust.
- **All notifications in one place.** The AI activity indicator, update notices, short confirmations, errors and AI location cards now stack in the bottom-right corner, clear of the PDF bottom bar and the note bar scrollbar. Toasts can be closed, pause while hovered, and repeated messages merge. The AI change list opens upward from its indicator, with Undo all.

## Fixed

- Context menus opened near the bottom or right edge of the window could be cut off; they now always fit, and scroll if taller than the window.
- Long section titles in notes used to leave empty space on the right; only the first line now makes room for the section controls.
- Version-group rows in the left bar: the version label and chevron no longer get clipped in a narrow left bar, and the "new note" + button stays on the row when the version list is expanded.
