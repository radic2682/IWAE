# IWAE v0.2.4

One detachable toolbar for every document, a window that opens where you left it, and a large round of fixes for saving, password-protected PDFs, backups, the memo editor and keyboard use.

## New

- **One toolbar you can detach.** The grip at the far left of the top bar tools now moves the whole toolbar for PDFs, Markdown files and notes. Once you float it, it stays at that spot when you switch to another pane or document. Drag it back onto the top bar or press its pin to dock it.
- **The window opens where you left it.** IWAE no longer appears in the middle of the screen first and then jumps to its remembered position and size.

## Changed

- There is no line between the top bar and the panes.
- In small windows the toolbar folds into "⋯" instead of overflowing, and screen tabs shorten their names instead of overlapping.
- Narrow panes keep the open tab's title visible.
- The floating translator gets smaller in small windows and returns to its size when the window grows.
- Shrinking the window keeps every pane at its minimum width by narrowing the left bar first.
- Keyboard: switching panes moves keyboard focus too, toolbar menus open with the first item focused and work with the arrow keys, dialogs keep focus inside, and Escape closes popovers.
- A link to a PDF inside a Markdown file opens that PDF. Links that can't be opened show a short notice.
- The link confirm says "Open in mail app" for email links.
- English UI: the remaining Korean strings are translated, counts use singular and plural, and new English setups back up to "IWAE Backups".

## Fixed

### Saving and data safety

- Typed memo or text-block text is kept when its pane closes or you switch screens before clicking away.
- A canvas or memo note that fails to save is retried instead of being dropped, and quitting asks before discarding unsaved changes.
- A damaged highlights, bookmarks or overlays file is set aside and reported, instead of silently stopping every save for that document. A file that is only briefly locked is read again.
- "Retry save" in recovery no longer applies a half-written file, one damaged recovery record no longer hides the others, and failed saves no longer leave temporary files behind.
- Saving a read-only note is refused instead of clearing its read-only flag.
- Version history is no longer flooded by rapid autosaves.
- The first memo in a new vault no longer creates a second, duplicate note.

### Password-protected PDFs

- Page edits on a password-protected PDF are refused instead of saving it without its password.
- Exports, inserting pages and merging use the password you already entered.
- Tools that make a new file from a protected PDF tell you the copy has no password.

### Backups and files

- Two vaults with the same folder name no longer delete each other's automatic backups.
- Automatic backups are pruned by time, so a time zone or daylight saving change no longer deletes the newest one. Two backups made in the same minute no longer overwrite each other.
- A locked file no longer stops a whole backup, and restore lists the files it had to skip.
- PDFs on a USB stick or network drive keep their access if the drive was not connected when IWAE started.
- Copying a file to the clipboard is safe for file names with curly quotes.
- A file named ".md" or ".pdf" no longer stops a vault from opening, and moving a file into the folder it is already in no longer fails.
- Files deleted outside IWAE are picked up while the vault is open.

### Notes and the memo editor

- Plain text such as "2026. 11. 15." or "---" no longer turns into a list or a line after reopening.
- Undo and redo work after Markdown shortcuts, inline code and checklists, and headings on list items can be undone.
- Typing in very long memos is fast again.
- Pasted links are kept, and Markdown export keeps headings, lists, checklists, tables and other formatting.
- The Markdown viewer hides YAML front matter.
- A new memo's card shows the document name instead of "Other document".

### PDFs and panes

- Ctrl+Z after a page edit no longer moves highlights back to their old pages, and highlighting works on pages that were moved.
- A tiny accidental drag with the region tool no longer saves a blank capture.
- The sample guide PDF renders sharply at high zoom and uses its real text in the desktop app.
- Joining a pane from another screen keeps that screen's floating panes, the active pane is never hidden behind a zoomed pane, and new screens get unused names.
- A note opened beside a PDF uses an empty pane when there is one instead of splitting the PDF pane.

### Translation and GitHub import

- Long text is no longer cut off at 5,000 characters.
- Showing the translation of a memo card no longer translates Korean into Korean.
- GitHub import updates files with Korean names, accepts folder links with spaces or Korean, ignores links that point outside the repository, and stops a clone that hangs.

### Other

- Automatic backup settings no longer leak from one vault into another, and a clock that ran ahead no longer stops automatic backups.
- The vault watcher is no longer restarted on every keystroke and is released when the window reloads.
- The bibliography file is no longer rewritten every time IWAE starts.
- PowerPoint conversion errors are readable on Korean Windows, and a conversion that hangs is stopped.
