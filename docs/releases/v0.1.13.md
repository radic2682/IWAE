# IWAE v0.1.13

Safer notes, shared tickets, page dragging between PDFs, and a much more capable MCP server for AI agents.

## New

- **Notes stay safe when other programs edit them.** If a note file changes on disk while IWAE is open (another program, a sync tool, an AI agent), IWAE reloads it in place. If you also have unsaved edits, it asks what to keep instead of overwriting: save yours as a copy, use the file's version, or keep yours. Saves never write over a newer file.
- **Insert a ticket anywhere.** The "+" between note blocks now offers "Add text" and "Add ticket". Pick from every ticket in the Vault by ID, title, note or quote.
- **Shared tickets stay in sync.** Blocks with the same ticket ID are the same memo: renaming a ticket's title or ID updates it in every note, and one undo restores them all. A "3 places" badge lists where a ticket appears and jumps there; different memos that share an ID are flagged instead of merged.
- **Drag pages to another PDF.** In Edit pages, drag pages (with a stacked preview) onto another PDF's tab. Its page editor opens with the pages inserted as pending; nothing is written until you press Save, and a backup is kept.
- **Show the source quote from the card.** Click the color dot on a memo card to expand or collapse the full quote.
- **Highlights from other notes are dimmed.** With a note open, highlights whose memos are not in that note are drawn faintly (hover shows which note they belong to). Settings → Display & documents → "Highlights from other notes": Normal, Dimmed (default), or Hidden.
- **MCP for AI agents, greatly expanded.** Agents now get a guide to how IWAE works (memos, notes, tickets) plus tools to create notes attached to a PDF, build a whole note with highlight-linked memo cards in one call, move blocks, read the app state, open documents and split panes, manage bookmarks and favorites, translate text, run safe PDF tools (always to a new file) and undo their own changes. An "AI is editing" pill shows what changed, with Undo all. Writes are rate-limited and deletions go to the trash.

## Improved

- Update results now appear inside Settings → Updates (checking, up to date, new version with an install button, download progress, ready to restart), and the app re-checks every 6 hours while open.
- The doc toolbar and the tool options row read as one bar, and the "Shift: horizontal, vertical or 45°" hint no longer squishes in narrow panes.
- Long section titles in notes wrap instead of being cut off.
- The command palette's search field keeps its height.
- The note bar header no longer shows the "This PDF n" chip, leaving room for the note title.
- Google Translate retries once on "too many requests".
- A PDF moved inside the Vault keeps its highlights and bookmarks at its new location.

## Fixed

- The source-highlight tooltip could be cut off at the edge of the page.
- Three-button confirm dialogs now fit on one row.
