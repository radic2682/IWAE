# IWAE v0.1.16

Text box formatting, clearer PDF tool names, and screenshots in problem reports.

## Added

- **Text box formatting.** Pick a font (Malgun Gothic, Batang, Gulim, Dotum, Gungsuh, Arial, Times New Roman, Courier New), type any size from 4 to 144 pt in 0.5 steps, and choose any background colour and border colour. Every change is its own undo step, and "Save PDF with annotations" keeps the new styles.
- **Format sampler.** The eyedropper in the text box strip copies the style of another text box, or the size, font and colour of text in the PDF. On scanned pages the size is estimated from the image.
- **Screenshots in problem reports.** The report dialog can capture the app window (without the dialog) and put it on the clipboard, ready to paste into the GitHub issue with Ctrl+V, or save it as a PNG.
- **Delete a note from the note bar.** The note menu next to the title has "Move this note to trash…", with a confirmation.

## Changed

- PDF tools use common names: Extract pages, Split PDF (by chapters), Merge PDFs, Delete blank pages, Save PDF with annotations, Save PDF with sensitive info removed, Save unlocked PDF, and more.
- Hovering a highlight from another note now also shows the start of that memo.
