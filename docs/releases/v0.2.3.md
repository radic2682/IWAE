# IWAE v0.2.3

A first-run tour that teaches the real reading loop, a movable format bar, an optional note minimap, and smoother pane work.

## New

- **A better first-run tour.** On a fresh install the sample guide PDF and the sample note open side by side on the same color channel. The tour then walks the real loop on them: highlighting, memo cards, color channels, region capture, the format bar, splitting panes, the prefix key, search, the menu and the translator. Steps whose target is not on screen are skipped.
- **Ctrl+Space is the recommended prefix key.** The first-run prefix key dialog lists it first and picks it for you, since it does not clash with Ctrl+B for bold in notes. Choosing Later still keeps Ctrl+B.
- **Movable format bar.** Drag the grip at the far left of the top bar tools to float the format bar, dock it back, or centre it. It also has more contrast in the dark theme.
- **Note minimap.** Turn on a VS Code style minimap in a note to see the whole note and jump to any part. It is off by default and replaces the automatic outline.

## Changed

- The ＋ in the screen tabs makes a blank screen at once. Right-click it for templates.
- A PDF dragged in from outside the app opens in the pane under the cursor instead of being imported into the left bar.
- With only one pane shown, opening a note from the left bar opens it as a tab in that pane.
- Region capture with no note visible saves the memo quietly and shows a notice instead of opening a note.
- Pane borders are a little thicker, with a line under the top bar and above each pane's bottom bar. Zoom and close sit on the pane head.
- The left bar's old 90% size is now shown as 100%. Your saved size stays the same.
- Recent PDF dates line up on the right.

## Fixed

- Dragging the divider between two PDF panes no longer lags.
- Region pictures in note cards no longer grow without limit when the note pane is widened.
