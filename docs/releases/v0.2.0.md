# IWAE v0.2.0

A new workspace built around panes and screens, drag and drop for panes, tabs and memos, and guided tours.

## New

- **Panes, screens and sessions.** Split any pane left-right or top-bottom, as many times as you need. Each pane has its own head with a color dot, a number and its tabs. A screen is a set of panes; switch screens from the tabs in the top bar and save them as named sessions. Templates (Reading, Note left, Compare, Blank) start a new screen in one step.
- **Prefix keys.** Press Ctrl+B, release it, then press a key: `%` and `"` split, arrow keys move between panes, `z` zooms a pane, `x` closes it, `c` makes a new screen, `?` lists every key. The same commands work in the command palette after `:` (for example `split-window -h`). You can change the prefix key in Settings or in `.iwae/keys.conf`.
- **Floating panes.** Pop a pane out over the screen from its ⋯ menu, move it by its head and resize it from the corner.
- **More app windows.** Ctrl+Shift+N opens a second window attached to the same session. Each window can show a different screen, and edits appear in both.
- **Drag a pane by its head.** Drop it on the edge of another pane to move it there, or on the middle to swap the two panes.
- **Tear off notes and Markdown.** Drag a note or Markdown tab out of the window to open it in a new window. Drop it on another window's tab bar to bring it back.
- **Move memos between notes.** Drag a memo card onto a note in another pane to move it there. Hold Alt when you drop to add a link instead and keep the original. Hovering a note tab for a moment opens it so you can drop into it. Ctrl+Z undoes the move in both notes.
- **Link panes by dragging the color dot.** Drag a pane's color dot onto another pane to give both the same color. Panes of the same color follow each other: clicking a memo scrolls the document, and new memos go to the note named in the toolbar ("→ note name").
- **Getting started tour.** The first time you open a vault, a short tour points out the left bar, panes, the toolbar, color channels, prefix keys and the translator. After an update, the "What's new" dialog offers a tour of the new features. Both are in the command palette and the logo menu.

## Changed

- **The toolbar moved to the top bar.** The tools of the pane you are working in appear in the top bar, next to the screen tabs.
- **No status bar.** Prefix key hints appear in a small chip in the top bar, commands run from the command palette, and Ctrl+B ? shows the key list.
- **The translator is a window over the app.** Open it from the button at the right of the top bar. It stays in place across panes and windows.
- **Calmer motion.** Menus, cards and new tabs fade in instead of bouncing.
- **Clearer wording.** Labels, tooltips and messages were rewritten to be shorter and consistent, in Korean and English. The PDF tools use the same names as the command palette.
- **The user guide and sample notes** describe the new workspace.

## Fixed

- `.markdown` files open like `.md` files.
- Single-key tool shortcuts and the prefix key no longer act on the panes behind an open dialog.
- Choosing an item in a pane's menu no longer clicks the card underneath it.
- Typing in Korean no longer runs a command when Enter only finishes the composition.

## For AI clients (MCP)

- New tool `workspace_command` runs the same commands as the prefix keys and the `:` command line, and returns the resulting workspace state.
- `app_state` changed shape:
  - `layout.active_pane` is now a number (the index in `panes[]`) instead of a name such as `left`. The pane id is in `layout.active_pane_id`.
  - Pane ids are opaque. Pass back the values you read from `panes[].id`, or use a pane number, `active` or `other`.
  - Tab kinds are `memoNote` for notes (was `note`) and `canvas` for canvases.
  - New fields: `screens`, `session`, `clients`, `floats` and `layout.active_float`.
