# IWAE v0.2.2

One shared format bar, a calmer top bar and clearer cards, plus fixes for tab dragging.

## Changed

- **One format bar everywhere.** Note memos, Markdown and PDF text boxes, and canvas text blocks now use the same format bar, with the same buttons, menus, color pickers and the same ⋯ folding on narrow panes. Each place shows only the groups it needs.
- **Calmer top bar.** The tools of the focused pane sit on one soft background instead of inside an outline, and the pane area now starts right under the top bar.
- **Memo cards stand out in the light theme.** Cards are white on the gray pane, like in the dark theme.
- **Quieter connector lines.** Lines that reach a pane further away stay faint until you point at the memo or its highlight.
- **Translator.** The Copy button sits next to Translate, and the close button is at the right edge.
- **Update history** in Settings is one simple list instead of boxes inside a box.

## Fixed

- Dragging a tab to the edge of the workspace no longer shows two competing split previews or flickers. The full-height column appears only when it gives a different result from splitting the pane at that edge.
- In a torn-off window, dragging a tab no longer moves the whole window. It behaves like any tab drag, and releasing it over another window's tab bar attaches it there.
- The close button of a tab was cut off in narrow panes.
