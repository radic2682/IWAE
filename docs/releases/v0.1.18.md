# IWAE v0.1.18

Fixes a bug in v0.1.17 that could erase a memo's text.

## Fixed

- **Clicking a highlight again no longer erases its memo.** In v0.1.17, clicking the same highlight a second time while its memo was open could save the memo as empty. The note bar had stopped drawing the card at the moment the editor closed, so its text read as blank. Cards being edited are now always drawn, and a memo is never saved as empty while its editor still holds text.
- **Undo is one step again.** Saving a memo without changing it no longer adds an empty undo step, so a single Ctrl+Z goes back to the last real change.

If a memo was erased in v0.1.17, click outside the memo and press Ctrl+Z a few times while the app is still open. Earlier versions of the vault data are also kept in `.iwae/history` inside the vault.
