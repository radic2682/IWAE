# 안내 둘러보기 (처음 사용 안내 · 새 기능 둘러보기)

앱 처음 설치 때는 「처음 사용 안내」, 업데이트로 새 기능이 들어온 버전에서는 그 버전의 「새 기능 둘러보기」를 한 번 보인다.
둘 다 같은 말풍선 엔진(`src/app/TourHost.tsx` + `src/ui/tour.css`)을 쓴다.

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `src/core/tours.ts` | 둘러보기 자료(`TOURS`)와 순수 규칙 `planTours` |
| `src/core/tourPlacement.ts` | 구멍 네모와 카드 자리 계산(순수) |
| `src/app/tourState.ts` | 본 목록(localStorage `iwae:tours-seen:v1`), 시작 순간의 설치 흔적, 직접 열기 신호 |
| `src/app/TourHost.tsx` | 언제 띄울지(시작 대화상자 줄) + 화면(`TourOverlay`) |
| `src/app/WhatsNewDialog.tsx` | 새 기능 안내가 있으면 확인 단추가 「새 기능 둘러보기」, 보조 단추가 「나중에」 |

## 언제 뜨는가

- 메인 창에서만, 시작이 끝나고 Vault 가 열려 칸이 그려진 뒤(`TourHost enabled`). 떼어 낸 창·새 창은 저절로 뜨지 않는다.
- 시작 대화상자 줄(`startupDialogs`)에서 차례는 「새 버전」(10) → 접두키 고르기(50) → 둘러보기(60). 겹쳐 뜨지 않는다.
- 처음 설치(`iwae:last-seen-version:v1` 도 없고 쓴 흔적도 없음)면 처음 사용 안내만 보이고, 지금 버전까지의 새 기능 안내는 본 것으로 적는다.
  쓴 흔적은 `last-seen-version`, `onboarded`(Vault 고르기), `app-prefs`, `launch-seen` 중 하나라도 있는 것이다.
  「새 버전」 창이 마지막 버전을 적기 전의 값으로 가려야 하므로 모듈을 불러올 때 한 번 찍어 둔다(`captureInstallSnapshot`).
- 업데이트면 마지막 버전 뒤 ~ 지금 버전 사이에 들어간 새 기능 안내 중 안 본 것을 오래된 것부터 보인다. 쓰던 사람은 처음 사용 안내를 저절로 받지 않는다.
- 「새 버전」 창이 같이 뜨면 거기서 「새 기능 둘러보기」를 눌러야 시작한다. 「나중에」 · Esc · 「지난 기록 보기」는 본 것으로 쳐서 다시 재촉하지 않는다.
- 팔레트(「처음 사용 안내」 · 「새 기능 둘러보기」)와 로고 메뉴에서는 본 적이 있어도 언제든 연다.
- 마치거나 건너뛰면(Esc · ×) 본 것으로 적는다.

## 새 버전에 둘러보기 더하기

1. `src/core/tours.ts` 의 `TOURS` 에 `kind: 'feature'`, `version`(그 버전이 처음 들어간 릴리스, 'v' 없이), `name: '새 기능 둘러보기'` 로 `Tour` 를 더한다. id 는 `v0.1.21` 꼴.
   첫 단계는 목표 없는 소개 카드, 나머지는 `target` 이 있는 단계로 짠다. 본문은 합니다체 한두 문장, 접두키는 `{prefix}`.
2. 목표가 새로 필요하면 그 요소에 `data-tour="이름"` 을 단다(보이는 모양은 그대로). 같은 이름이 여럿이면 만지는 칸(`.pane-card-active`) 안의 것을 먼저 쓰고, 그다음 처음으로 보이는 것을 쓴다. 보이지 않으면 가운데 카드로 보인다.
3. 새 한국어 글(이름 · 단계 제목 · 본문)을 `src/i18n/en/tours.ts` 에 영어로 더한다.
4. `latestFeatureTour()` 가 가장 새 버전을 돌려주므로 「새 기능 둘러보기」 명령은 따로 고칠 것이 없다. `package.json` 버전이 그 버전이 되면 업데이트한 사람에게 저절로 뜬다(그 버전의 `docs/releases/vX.md` 가 있어야 「새 버전」 창과 이어진다).
5. `src/core/tours.test.ts` 의 등록부 시험(단계 수 등)을 맞춘다.

## 엔진 규칙

- 목표 둘레 6px 여백, 반지름 8px 구멍과 1.5px 강조색 고리. 구멍은 `box-shadow` 100vmax 로 나머지를 어둡게 한다(`--rgb-night` 토큰).
- 어두운 곳도 구멍도 클릭을 통과시키지 않는다(안내만 한다). Esc 건너뛰기, → · Enter 다음, ← 이전. 카드는 `aria-modal` 이라 뒤 단축키가 막힌다.
- 카드는 구멍을 가리지 않는다. auto 는 아래 → 위 → 오른쪽 → 왼쪽 순서, 창 가장자리에서 12px 안쪽.
- 창 크기 · 스크롤 · 목표 크기가 바뀌면 다시 재고, 400ms 마다 목표가 아직 있는지 본다. 사라지면 가운데 카드가 된다.
- 움직임은 카드·구멍 투명도 120ms, 구멍 이동 180ms ease-out 뿐이다. `prefers-reduced-motion` 에서는 모두 끈다.
