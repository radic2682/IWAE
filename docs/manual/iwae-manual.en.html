IWAE User Guide

A desktop app for reading long PDFs, marking them up, and weaving your notes together

This guide ships as an example in every new Vault. Try highlighting and adding memos while you read it.

The Tour of IWAE note in the Notes list on the left already holds memos and tickets made on this guide.

1. Vault and screen

IWAE opens one folder called a Vault. Your PDFs and Markdown files stay in that folder as they are, and the app keeps its own records in a separate .iwae folder inside it.

A Vault is a plain folder, so you can copy or back it up with your file manager.

Screen layout

AreaWhat it does
Left barDocument list and note list. Group items into folders and drag to reorder.
CenterPDF and Markdown viewer. Open several documents in tabs, or split the view to read two side by side.
Right barThe open note. It scrolls separately from the PDF, and lines connect each memo to its highlight.

2. PDF tools

Switch tools with the buttons in the toolbar above the document.

ToolWhat it does
HandDrag empty space to move the page. Dragging over text only selects it for copying.
Text selectDrag over text to highlight it and open a memo in the note on the right.
Region captureDraw a box around a table or figure to add it to the note as an image.
Box memoAttach a memo box in the PDF margin, connected by a line.
Text box · Pen · Eraser · LineWrite and draw directly on the PDF. Pick color and width in the floating format bar.
Edit pagesReorder pages in a thumbnail view, insert pages from another PDF, remove or rotate them.

You can resize a captured table or figure box by dragging its edges and corners with the text select or region capture tool.

Find and navigate

Press Ctrl+F to search inside the PDF, and use the outline and page thumbnails to jump around. Click a link in the document to follow it, or hover to preview it.

3. Memos and notes

A note is a document built from blocks. One note can mix memos from several PDFs.

BlockDescription
SectionGroups the blocks below it. Collapse to hide them, drag to move them together.
TextText you write in the note, with bold, lists, tables and code.
MemoA PDF highlight with your memo. Click it to jump to that spot in the PDF.
TicketA memo shown as title, your text and the original quote. Handy for tracking requirements.

Hover over a block to see its source at the top right of the block.

Drag the handle on the left to change the order of blocks.

Choose Convert to ticket in a memo block's menu to make it a ticket.

4. Practice: tracking requirements

Below are practice requirements. Drag over one line with the text select tool to make a memo, then turn it into a ticket from the memo menu.

REQ-01 Saved notes must still be there after the app restarts.
REQ-02 Deleting a highlight must also remove its memo block from the note.
REQ-03 Highlights must point to the same text after pages are reordered.
REQ-04 Text to translate must only be sent where the user chose.

The example note in this Vault already has REQ-01 and REQ-03 as tickets.

5. Translation

You can translate selected text right away. Choose how in Settings, under Translation.

MethodNotes
Local (Ollama)Text never leaves your PC. Can be slow depending on the model size.
Cloud APIFast translation with Claude, OpenAI, Gemini and others. Selected text is sent to that service.

Cloud API keys are kept in this PC's credential store.
