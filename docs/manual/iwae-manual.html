IWAE 사용 설명서

긴 PDF 를 읽고, 표시하고, 메모를 노트로 엮는 데스크톱 앱

이 설명서는 새 Vault 에 예시로 들어 있습니다. 직접 형광펜을 칠하고 메모를 달아 보면서 읽어 보세요.

왼쪽 「노트」의 IWAE 둘러보기 노트에는 이 설명서에 단 메모와 티켓이 들어 있습니다.

1. Vault 와 화면

IWAE 는 Vault 라는 폴더 하나를 엽니다. PDF 와 Markdown 은 이 폴더에 그대로 두고, 앱이 쓰는 기록은 폴더 안의 .iwae 에 따로 둡니다.

Vault 는 평범한 폴더라서 탐색기로 복사하거나 백업할 수 있습니다.

화면 구성

자리하는 일
왼쪽 바문서 목록과 노트 목록. 폴더로 묶고 끌어서 차례를 바꿉니다.
가운데PDF·Markdown 보기. 탭으로 여러 문서를 열고, 둘로 나눠 나란히 볼 수 있습니다.
오른쪽 바열린 노트. PDF 와 따로 스크롤하며, 메모와 PDF 형광펜이 선으로 이어집니다.

폴더 구조

경로내용
*.pdf, *.md내 문서
노트/*.iwnote노트 파일
.iwae/형광펜, 책갈피, 색인 같은 앱 기록

2. PDF 도구

문서 위 도구줄의 단추로 도구를 바꿉니다.

도구하는 일
손 도구빈 곳을 잡고 끌어 화면을 옮깁니다. 글자 위에서 끌면 글을 골라 복사만 합니다.
텍스트 선택글을 끌면 형광펜이 칠해지고 오른쪽 노트에 메모 칸이 열립니다.
영역 캡처표나 그림을 네모로 잡아 노트에 그림으로 넣습니다.
박스 메모PDF 여백에 선으로 이어진 메모 상자를 붙입니다.
글 상자 · 펜 · 지우개 · 선PDF 위에 직접 쓰고 그립니다. 떠 있는 서식 창에서 색과 굵기를 고릅니다.
쪽 편집쪽 미리보기에서 순서를 바꾸고, 다른 PDF 의 쪽을 끼우고, 빼고, 돌립니다.

잡아 둔 표·그림 네모는 텍스트 선택이나 영역 캡처 도구에서 변과 모서리를 끌어 크기를 바꿀 수 있습니다.

찾기와 이동

Ctrl+F 로 PDF 안을 찾고, 목차와 쪽 미리보기로 원하는 곳에 갑니다. 문서 안의 링크를 누르면 그 자리로 가고, 마우스를 올리면 미리 보입니다.

3. 메모와 노트

노트는 블록을 쌓아 만드는 문서입니다. 한 노트에 여러 PDF 의 메모를 섞어 담을 수 있습니다.

블록설명
소제목아래 블록을 묶습니다. 접으면 숨고, 끌면 묶인 블록과 함께 옮겨집니다.
글노트에 직접 쓰는 글입니다. 굵게, 목록, 표, 코드를 쓸 수 있습니다.
메모PDF 형광펜과 그 메모입니다. 누르면 PDF 의 그 자리로 갑니다.
티켓제목, 내 글, 원문 순서로 보이는 메모입니다. 요구사항을 정리할 때 씁니다.

블록에 마우스를 올리면 블록 오른쪽 위에 출처가 보입니다.

왼쪽 손잡이를 잡고 끌면 블록 차례를 바꿀 수 있습니다.

메모 블록의 메뉴에서 티켓으로 바꾸기를 누르면 티켓이 됩니다.

4. 연습: 요구사항 정리하기

아래는 연습용 요구사항입니다. 텍스트 선택 도구로 한 줄을 끌어 메모를 만든 뒤, 메모 메뉴에서 티켓으로 바꿔 보세요.

REQ-01 저장한 노트는 앱을 다시 켜도 그대로 남아야 한다.
REQ-02 형광펜을 지우면 그 메모 블록도 노트에서 빠져야 한다.
REQ-03 쪽 순서를 바꿔도 형광펜은 같은 글을 가리켜야 한다.
REQ-04 번역할 글은 사용자가 고른 곳으로만 보내야 한다.

이 Vault 의 예시 노트에는 REQ-01 과 REQ-03 이 이미 티켓으로 들어 있습니다.

5. 번역

고른 글을 바로 번역할 수 있습니다. 설정의 번역에서 방식을 고릅니다.

방식특징
로컬 (Ollama)글이 PC 밖으로 나가지 않습니다. 모델 크기에 따라 느릴 수 있습니다.
클라우드 APIClaude, OpenAI, Gemini 등으로 빠르게 번역합니다. 고른 글이 그 서비스로 전송됩니다.

클라우드 API 키는 이 PC 의 자격 증명 저장소에 보관됩니다.
