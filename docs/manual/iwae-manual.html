한 쪽 요약

IWAE는 PDF와 Markdown을 읽으며 남긴 표시를 원문과 이어진 노트로 엮는 데스크톱 앱입니다.

1 왼쪽 바문서와 노트 목록이 있습니다. 맨 위 줄의 탭으로 탐색기, 목록, 미리보기, PDF 도구, 검색을 오갑니다.
2 칸 머리색 점, 칸 번호, 탭 줄이 있습니다. 머리를 끌어 칸을 옮깁니다.
3 문서 칸PDF와 Markdown을 읽습니다. 칸을 나눠 여러 문서를 나란히 봅니다.
4 도구줄선택한 칸의 도구가 맨 위 줄에 나옵니다. 손, 텍스트 선택, 영역 캡처, 형광펜, 박스 메모, 글 상자, 펜, 지우개, 쪽 편집이 있습니다.
5 노트 칸노트도 탭이라 자기 칸에 열립니다. 메모 카드가 PDF의 형광펜과 선으로 이어집니다.
6 아래 막대문서 칸마다 있습니다. 쪽 이동, 폭·쪽·높이 맞춤, 확대와 축소를 합니다.
7 맨 위 줄세션 이름, 화면 탭, 번역기 단추가 있습니다.

Vault와 화면

IWAE는 Vault라는 폴더 하나를 엽니다.

PDF와 Markdown은 이 폴더에 두고, 앱이 쓰는 기록은 폴더 안의 .iwae에 따로 둡니다. Vault는 평범한 폴더라서 탐색기로 복사하거나 백업할 수 있습니다. 문서를 앱 안에 가두지 않으니, IWAE를 지워도 파일은 남습니다.

Vault 폴더 안

경로내용
*.pdf · *.md내 문서. 하위 폴더도 폴더 구조대로 왼쪽 목록에 나타납니다.
노트/*.iwnote노트 파일
.iwae/형광펜, 책갈피, 검색 색인, 번역 캐시, 이력, 세션, 휴지통 같은 앱 기록

문서 열고 정리하기

  • 왼쪽 「탐색기」에서 문서를 누르면 탭으로 열립니다. 새 폴더 만들기, 이름 바꾸기, 끌어서 옮기기도 여기서 합니다.
  • 「문서 추가」로 파일을 가져오거나, 파일 탐색기에서 문서를 Vault 폴더 위로 끌어다 놓습니다.
  • GitHub 단추로 저장소의 Markdown 문서 폴더를 가져옵니다(10쪽).
  • 파일 탐색기에서 PDF를 직접 열면 Vault로 가져오지 않고 열립니다. 왼쪽 아래 「최근 연 PDF」에 남고, Vault 폴더로 끌어 놓으면 가져옵니다.
  • 왼쪽 아래의 Vault 이름을 누르면 다른 Vault로 바꿉니다. 읽던 쪽과 열어 둔 탭은 다음 실행에도 이어집니다.

화면의 구성

맨 위 줄왼쪽 바 보기 탭, 세션 이름, 화면 탭, 지금 칸의 도구줄, 번역기 단추가 있습니다.
왼쪽 바문서와 노트 목록, 목차, 쪽 미리보기, PDF 도구, 검색. 폭은 경계를 끌어 바꿉니다.
칸문서와 노트는 모두 탭이고, 탭은 칸에 모입니다. 칸마다 머리(색 점, 번호, 탭 줄)와 도구가 따로 있습니다. 노트도 자기 칸에서 따로 스크롤됩니다. 칸을 나누는 방법은 4쪽에 있습니다.
알아 두기PC 밖으로 나가는 것은 클라우드 번역에 보낸 글, 업데이트 확인, 직접 켠 외부 AI 연결의 요청뿐입니다. 자세한 내용은 11쪽에 있습니다.
해 보기
  1. 왼쪽 「탐색기」에서 Markdown 예시를 눌러 새 탭으로 엽니다.
  2. 탭을 눌러 이 설명서와 Markdown 예시를 오갑니다.
  3. 「새 폴더」 단추로 폴더를 만들고 이름을 「연습」으로 바꿉니다. 연습이 끝나면 지워도 됩니다.

탭, 칸, 화면

문서마다 탭이 생기고, 탭이 모인 칸을 나눠 여러 문서를 나란히 읽습니다.

칸탭이 모이는 곳입니다. 칸마다 머리의 탭 줄과 도구가 따로 있습니다.
화면칸을 모아 둔 한 장입니다. 맨 위 줄의 화면 탭(「0 읽기」 「1 비교」처럼)으로 오갑니다.
세션화면 여러 개를 이름 붙여 저장한 것입니다. 맨 위 줄의 세션 이름에서 바꾸고 저장합니다.

접두키로 칸 나누기

접두키(기본 Ctrl+B)를 눌렀다 놓은 다음 아래 키를 누릅니다. 칸 머리의 「⋯」 메뉴에도 같은 일이 있습니다. 2초가 지나거나 Esc를 누르면 취소됩니다.

칸% 좌우로 나누기, " 위아래로 나누기, ← ↑ → ↓ 이동, z 이 칸 확대(다시 누르면 원래 크기), x 닫기, { } 자리 바꾸기, Space 배치 돌리기, q 번호로 이동
화면! 칸을 새 화면으로, c 새 화면, n p 다음, 이전 화면, 0~9 번호로 이동
그 밖f 떠 있는 칸 숨기기와 보이기, w 번역기 열기와 닫기, ? 키와 명령 목록

입력기 때문에 안 되면 명령 팔레트(Ctrl+K)에 split-window -h처럼 명령을 입력하세요.

새 화면과 떠 있는 칸

  • 맨 위 줄의 「새 화면」으로 화면을 더합니다. 템플릿은 「읽기」, 「노트 왼쪽」, 「비교」, 「빈 화면」입니다.
  • 칸 머리 「⋯」의 「띄우기」는 칸을 화면 위로 꺼냅니다. 머리를 끌어 옮기고 모서리로 크기를 바꿉니다.

끌어서 정리하기

탭을 같은 칸에서 끌기순서가 바뀝니다.
탭을 다른 칸의 탭 줄로 끌기그 칸으로 탭이 옮겨 갑니다.
탭을 칸 가장자리로 끌기탭을 칸 가장자리로 끌면 그쪽에 새 칸이 생깁니다.
탭을 창 밖으로 끌기새 앱 창으로 떨어져 나갑니다. 탭 줄로 끌어 오거나 「다시 붙이기」를 고르면 돌아옵니다.
칸 머리 끌기다른 칸 위에 놓으면 두 칸이 자리를 바꾸고, 가장자리에 놓으면 그쪽으로 나뉘어 옮겨 갑니다.

새 창(Ctrl+Shift+N)은 같은 세션에 붙는 두 번째 앱 창입니다. 한쪽에서 칠하거나 쓴 내용이 다른 쪽에 나타나고, 같은 파일을 동시에 고쳐도 서로 덮어쓰지 않고 합쳐집니다.

보기와 이동

  • 쪽 배치는 한 장, 두 장, 세 장, 연속 보기입니다. 아래 막대에서 맞춤과 확대를 고릅니다.
  • Ctrl+G로 쪽으로 이동합니다. 문서 안 링크는 마우스를 올리면 미리 보이고, 누르면 이동합니다.
해 보기
  1. 문서 칸 머리의 「⋯」를 눌러 「오른쪽으로 나누기」를 고릅니다.
  2. Markdown 예시 탭을 새 칸으로 끌어 놓고, 두 문서를 나란히 읽습니다.
  3. 탭 하나를 창 밖으로 끌어 떼어 낸 뒤, 탭 줄로 다시 끌어 붙입니다.

형광펜과 메모

읽는 일과 남기는 일을 한 동작으로 합니다. 글을 고르면 형광펜이 칠해지고, 노트에 메모 칸이 열립니다.

해 보기 1
  1. 도구줄에서 「텍스트 선택」이 켜져 있는지 봅니다(처음부터 켜져 있습니다). 노트가 보이지 않으면 Ctrl+Shift+M으로 문서 옆에 엽니다.
  2. 아래 연습 문장을 끌어서 고릅니다. 형광펜이 칠해지고 노트에 메모 칸이 열립니다.
  3. 메모를 쓰고, 문서를 멀리 내려갔다가 메모 카드를 눌러 봅니다. PDF가 칠한 문장으로 돌아옵니다.

연습 1읽다가 멈춘 문장에 형광펜을 칠하면, 그 문장이 노트에 메모 카드로 생깁니다.

연습 2칠한 문장은 노트의 메모 카드와 가는 선으로 이어집니다.

연습 3메모 카드를 누르면 PDF가 칠한 문장으로 돌아옵니다.

글을 골랐을 때

텍스트 선택 도구로 끌기형광펜을 칠하고 메모 칸을 엽니다.
손 도구로 글 위를 끌기칠하지 않고 글만 고릅니다. 복사할 때 씁니다.
고른 글 위의 단추복사, 출처 복사, 문서 검색, 번역
칠한 곳을 누르기노트에서 그 메모 카드가 열려 고칠 수 있습니다. 노트가 보이지 않으면 문서 옆에 엽니다. 어느 노트에도 없는 형광펜은 색 바꾸기, 메모 쓰기, 삭제를 하는 작은 상자가 뜹니다.
메모 카드의 출처 누르기PDF가 그 자리로 갑니다. 카드 메뉴의 「원문에서 보기」도 같고, 「형광펜과 메모 지우기」로 지웁니다.

색 고르기

「형광펜」 도구는 메모 없이 색만 칠합니다. 기본 색은 아래 네 가지입니다. 설정의 「화면 및 문서 → 형광펜 색」에서 이름 붙인 색을 8가지까지 더하고 끌어서 순서를 바꿉니다.

색 채널과 이어진 선

칸 머리의 색 점이 색 채널입니다. 파랑, 초록, 주황 중에서 고르고, 「없음」이면 연동하지 않습니다. 같은 색이면서 이웃한 문서 칸과 노트 칸은 형광펜과 메모 카드가 선으로 이어지고, 선은 형광펜과 같은 색입니다. 점을 누르면 색이 바뀌고, 다른 칸으로 끌면 그 칸과 이어집니다. 이웃하지 않은 칸의 카드에는 「→ 문서 이름」이 붙습니다. 눈 모양 단추 「표시 모두 숨기기」는 형광펜, 메모, 선을 숨깁니다. 되돌리기(Ctrl+Z)는 형광펜, 그림, 메모 노트의 변경을 되돌리며 다른 창에서 더한 내용은 건드리지 않습니다.

해 보기 2
  1. 「형광펜」 도구로 바꾸고 색을 골라 문장 몇 개를 칠합니다.
  2. 칠한 문장을 눌러 노트의 카드가 열리는 것을 보고, 카드 메뉴의 「형광펜과 메모 지우기」로 지웁니다. 눈 모양 단추로 표시를 숨겼다가 다시 켭니다.

표와 그림처럼 글이 아닌 것은 영역 캡처로 담고, 쪽 위에는 직접 쓰고 그립니다.

영역 캡처

도구줄의 「영역 캡처」로 표나 그림을 네모로 감싸면, 노트에 그림이 설명 칸과 함께 들어갑니다. 잡아 둔 네모는 변과 모서리를 끌어 크기를 바꿀 수 있습니다. Ctrl을 누른 채 끌어도 표와 그림을 감쌀 수 있습니다. 글자 없는 스캔 쪽에서 영역을 잡으면 OCR로 읽은 글자도 함께 붙습니다.

박스 메모와 그리기

「박스 메모」는 쪽 여백에 메모 상자를 붙이고 선으로 잇습니다. 「글 상자」, 「펜」과 그리기 도구(선, 화살표, 네모, 동그라미), 「지우개」는 PDF 위에 직접 씁니다. 색과 굵기는 서식 상자에서 고릅니다. 지우개는 그림뿐 아니라 형광펜과 박스 메모도 지웁니다.

노트와 티켓

노트는 블록을 쌓아 만드는 문서입니다. 한 노트에 여러 PDF와 Markdown의 메모를 섞어 담을 수 있습니다.

블록설명
소제목아래 블록을 묶습니다. 접으면 숨고, 끌면 묶인 블록이 함께 옮겨집니다.
글노트에 직접 쓰는 글입니다. 굵게, 목록, 표, 코드를 쓸 수 있습니다.
메모내 글 아래에 출처(쪽 번호)가 붙습니다. 출처를 누르면 PDF의 그 자리로 갑니다. 출처를 여럿(캡처 포함) 붙일 수 있습니다.
티켓ID와 제목이 붙은 메모입니다. 요구사항을 챙길 때 씁니다.

블록의 왼쪽 손잡이를 잡고 끌면 순서를 바꿀 수 있습니다. Ctrl 또는 Shift를 누르고 여러 블록을 골라 한꺼번에 끌 수도 있습니다.

블록을 다른 칸에 열린 노트 위로 끌어 놓으면 그 노트로 옮겨 갑니다. Alt를 누른 채 놓으면 링크가 생기고 원래 노트는 바뀌지 않습니다. Esc로 취소합니다.

ID와 제목(티켓)

메모에는 ID와 제목을 붙일 수 있습니다. 메모에 마우스를 올리면 오른쪽 위에 「+ ID」 「+ 제목」이 보이고, 메모 맨 앞에 REQ-04 처럼 써도 ID가 됩니다. 다음 번호를 제안하고, 노트에 이미 있는 ID면 알려 줍니다.

아래는 연습용 요구사항입니다. 한 줄씩 칠해 메모를 만들고 ID를 붙여 보세요.

REQ-01 저장한 노트는 앱을 다시 켜도 그대로 남아야 한다.
REQ-02 형광펜을 지우면 그 메모 블록도 노트에서 빠져야 한다.
REQ-03 쪽 순서를 바꿔도 형광펜은 같은 글을 가리켜야 한다.
REQ-04 번역할 글은 사용자가 고른 곳으로만 보내야 한다.

이 Vault의 예시 노트에는 REQ-01과 REQ-03이 티켓으로 들어 있습니다.

라이브러리 펼치기

왼쪽 바 위쪽의 「라이브러리 펼치기」(Ctrl+Shift+L)를 누르면 왼쪽 바가 전체 · 즐겨찾기 · 최근 열람 · 폴더 탐색으로 바뀌고, 오른쪽이 모든 문서의 표가 됩니다.

  • 제목, 저자, 연도 같은 논문 정보를 표에서 고치고, 정렬하고, 별표를 달고, 모음으로 묶습니다. 목록과 카드 보기를 오갑니다.
  • 논문 정보는 PDF나 Crossref에서 채우고, BibTeX 인용 정보를 복사할 수 있습니다.

버전 묶음

같은 문서의 초안, 수정본, 최종본을 한 문서의 버전으로 묶어 오갑니다. 파일 행의 메뉴에서 「다른 파일과 버전으로 묶기…」를 고르면 되고, 묶음을 풀어도 파일은 남습니다. PDF 도구의 「다른 버전과 글자 비교」(9쪽)는 두 버전에서 바뀐 곳만 나란히 보여 줍니다.

번역과 Markdown

원문은 바꾸지 않고, 고른 글만 번역해서 곁에 펼칩니다.

번역

글을 고르면 나타나는 단추 중 「번역」을 누르면 결과 카드가 뜹니다. 카드에는 언어, 번역 방식, 다시 시도, 원문과 함께 복사가 있습니다. 노트의 출처 줄마다 작은 번역 단추가 있고, 누르면 그 아래에 번역이 펼쳐집니다. 줄바꿈으로 끊긴 글은 이어 붙여 번역하고, 이미 대상 언어인 글은 다른 언어로 번역합니다.

번역기는 앱 창 위에 뜨는 패널입니다. 맨 위 줄의 번역기 단추나 접두키 w로 열고 닫습니다. 문서에서 고른 글을 입력칸에 넣거나 직접 쓴 글을 번역하고(Ctrl+Enter), 크기는 모서리를 끌어 바꿉니다. 설정의 「번역 사용」을 끄면 번역 단추와 번역기가 사라집니다.

방식특징
로컬 (Ollama)내 PC에서 번역합니다. 글이 PC 밖으로 나가지 않습니다. 모델 크기에 따라 느릴 수 있습니다.
클라우드Google 번역(키 없음), Azure Translator, DeepL, OpenAI, Anthropic, Gemini 중에서 고릅니다. 고른 글이 그 서비스로 전송됩니다.

연습 4클라우드 API 키는 이 PC의 자격 증명 저장소에 보관됩니다.

번역 캐시: 한 번 번역한 글을 같은 언어로 다시 번역하면 요청 없이 저장해 둔 결과를 씁니다. 설정의 「번역」에서 끄거나 지울 수 있고, 번역은 Vault의 .iwae 안에만 남습니다. 방식과 API 키도 같은 곳에서 고릅니다.

Markdown 문서

Markdown 문서도 PDF 옆 탭으로 열리고, 제목, 표, 코드, 할 일 목록과 목차를 보여 줍니다. 글을 골라 형광펜과 메모를 달고 영역 캡처를 하는 방법은 PDF와 같고, 메모는 같은 노트에 섞입니다. 모양은 설정의 「Markdown 문서 테마」에서 바꿉니다(원본 파일은 바뀌지 않습니다).

  • GitHub에서 가져오기: 왼쪽 「탐색기」 위의 GitHub 단추로 저장소의 Markdown 문서 폴더를 가져옵니다. 새 커밋이 있으면 알려 주고, 최신으로 받거나 브랜치, 태그, 커밋의 예전 버전으로 바꿔 볼 수 있습니다.
해 보기

  2. 그 글을 메모로 칠해 두고, 노트 카드의 출처 줄에 있는 번역 단추를 누릅니다.
  3. Markdown 예시 탭에서 문장 하나를 칠해 같은 노트에 메모를 만듭니다.

API 키Vault가 아니라 운영체제의 자격 증명 저장소에 보관합니다.
밖으로 나가는 것클라우드 번역에 보낸 글, 업데이트 확인, 외부 AI 연결을 켰을 때의 요청뿐입니다. 외부 AI 연결은 처음에는 꺼져 있고, 켜도 이 PC의 127.0.0.1에서만 받으며 토큰이 있어야 합니다.

외부 AI 연결과 업데이트

  • 외부 AI 연결: IWAE에는 채팅이 없습니다. 대신 Claude Code 같은 바깥 에이전트가 MCP 서버로 Vault를 검색하고, 쪽을 읽고, 메모를 더하거나 고칠 수 있습니다. 설정의 「외부 AI 연결」에서 켜고 보이는 명령을 한 번 실행합니다. PDF 파일은 바꾸지 못합니다.
  • 업데이트: 설정의 「업데이트」에서 자동 확인과 미리 내려받기를 정합니다. 서명을 검사하고, 설치는 내가 확인해야 시작됩니다.
해 보기
  1. Ctrl+,로 설정을 열어 「다크」로 바꾸고, 색 구성과 강조색을 하나씩 눌러 화면이 바뀌는 것을 봅니다.
  2. 형광펜 색에서 「색 추가」로 이름 붙인 새 색을 만들고, 이 쪽의 문장 하나를 그 색으로 칠합니다.
  3. Ctrl+Shift+P로 명령 팔레트를 열고 「다크」나 「새 창」을 입력해 봅니다.
