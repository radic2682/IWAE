Vault 와 화면

IWAE 는 Vault 라는 폴더 하나를 엽니다.

PDF 와 Markdown 은 이 폴더에 그대로 두고, 앱이 쓰는 기록은 폴더 안의 .iwae 에 따로 둡니다. Vault 는 평범한 폴더라서 탐색기로 복사하거나 백업할 수 있습니다. 문서를 앱 안에 가두지 않으니, IWAE 를 지워도 파일은 그대로 남습니다.

Vault 폴더 안

경로내용
*.pdf · *.md내 문서. 하위 폴더도 그대로 왼쪽 목록에 나타납니다.
노트/*.iwnote노트 파일
.iwae/형광펜, 책갈피, 검색 색인, 번역 캐시, 이력, 휴지통 같은 앱 기록

문서 열고 정리하기

  • 왼쪽 「탐색기」에서 문서를 누르면 탭으로 열립니다. 새 폴더 만들기, 이름 바꾸기, 끌어서 옮기기도 여기서 합니다.
  • 「문서 추가」로 파일을 가져오거나, 탐색기에서 문서를 Vault 폴더 위로 끌어다 놓습니다.
  • GitHub 단추로 저장소의 Markdown 문서 폴더를 가져올 수 있습니다 (10쪽).
  • 탐색기에서 PDF 를 직접 열면 Vault 로 가져오지 않고 열립니다. 왼쪽 아래 「최근 연 PDF」에 남고, 끌어서 Vault 폴더에 놓으면 가져옵니다.
  • 왼쪽 아래의 Vault 이름을 누르면 다른 Vault 로 바꿉니다. 읽던 쪽과 열어 둔 탭은 다음 실행에도 이어집니다.

화면의 세 부분

왼쪽 바문서와 노트 목록, 목차, 쪽 미리보기, PDF 도구, 검색. 폭은 경계를 끌어 바꿉니다.
가운데탭으로 여러 문서를 열고, 칸으로 나눠 나란히 봅니다.
오른쪽 노트 바열린 노트. PDF 와 따로 스크롤되고, 메모가 형광펜과 선으로 이어집니다.
알아 두기자료가 PC 밖으로 나가는 경우는 두 가지뿐입니다. 클라우드 번역을 골랐을 때 고른 글, 그리고 외부 AI 연결을 직접 켰을 때입니다. 자세한 내용은 11쪽에 있습니다.

탭과 화면 나누기

문서마다 탭이 생기고, 칸을 나눠 여러 문서를 나란히 읽습니다.

화면을 나누는 방법은 두 가지이고, 둘 다 같은 아홉 가지 배치를 씁니다.

창 나누기오른쪽 위 단추. 서로 다른 문서를 칸마다 엽니다. Ctrl+\ 를 누를 때마다 한 칸, 두 칸, 세 칸으로 돌아갑니다.
화면 나누기PDF 도구줄 단추. 같은 PDF 의 서로 다른 쪽을 함께 봅니다. 칸마다 쪽과 배율이 따로입니다.

탭은 브라우저 탭처럼 끕니다

같은 칸에서 끌기탭 순서가 바뀝니다.
다른 칸의 탭 줄로 끌기그 칸으로 탭이 옮겨 갑니다.
칸 가장자리로 끌기탭을 칸 가장자리로 끌어 가면 그 자리에 칸이 새로 생깁니다.
창 밖으로 끌기PDF 탭이 자기 창으로 떨어져 나갑니다. 그 창은 문서와 노트 바만 보이는 가벼운 창입니다.
탭 줄에 끌어 놓기떨어진 창을 닫거나 「다시 붙이기」를 고르면 탭이 쪽과 배율 그대로 돌아옵니다.

새 창 (Ctrl+Shift+N)은 같은 Vault 를 보는 두 번째 창입니다. 한 창에서 칠하거나 쓴 내용은 다른 창에 바로 나타나고, 두 창이 같은 파일을 동시에 고쳐도 서로 덮어쓰지 않고 합쳐집니다. 모니터가 둘이면 한쪽에 문서, 한쪽에 노트를 두고 읽을 수 있습니다.

보기와 이동

  • 쪽 배치는 한 장 · 두 장 · 세 장 · 연속 보기. 아래 막대에서 폭 맞춤, 쪽 맞춤, 높이 맞춤, 실제 크기(1:1)를 고르고 Ctrl+휠로 확대합니다.
  • Ctrl+G 로 쪽으로 갑니다. 문서 안 링크에 마우스를 올리면 미리 보이고, 누르면 이동합니다. 돌아올 때는 Alt+← 나 마우스 뒤로 단추를 씁니다.
해 보기
  1. 오른쪽 위 「창 나누기」에서 「좌우 둘」을 고릅니다.
  2. Markdown 예시 탭을 오른쪽 칸으로 끌어 놓고, 두 문서를 나란히 읽어 봅니다.
  3. 탭 하나를 창 밖으로 끌어 떼어 낸 다음, 탭 줄로 다시 끌어다 붙여 봅니다.

형광펜과 메모

읽는 일과 남기는 일을 한 동작으로 합니다. 글을 고르면 형광펜이 칠해지고, 오른쪽 노트에 메모 칸이 열립니다.

해 보기 1
  1. 도구줄에서 「텍스트 선택」이 켜져 있는지 봅니다 (처음부터 켜져 있습니다).
  2. 아래 연습 문장을 끌어서 고릅니다. 형광펜이 칠해지고 노트에 메모 칸이 열립니다.
  3. 메모를 쓰고, 문서를 멀리 내려갔다가 메모 카드를 눌러 봅니다. PDF 가 칠한 문장으로 돌아옵니다.

연습 1읽다가 멈춘 문장에 형광펜을 칠하면, 그 문장이 노트의 메모 카드로 옮겨 옵니다.

연습 2칠한 문장은 노트의 메모 카드와 가는 선으로 이어집니다.

연습 3메모 카드를 누르면 PDF 가 칠한 문장으로 돌아옵니다.

글을 골랐을 때

텍스트 선택 도구로 끌기형광펜을 칠하고 메모 칸을 엽니다.
손 도구로 글 위를 끌기칠하지 않고 글만 고릅니다. 복사할 때 씁니다.
고른 글 위의 단추복사 · 출처 복사 · 문서 검색 · 번역 · 노트로 보내기
칠한 곳을 누르기노트에서 그 메모 카드가 열려 바로 고칠 수 있습니다. 노트 바를 닫아 두었다면 색 바꾸기, 메모 쓰기, 노트로 보내기, 삭제를 하는 작은 창이 뜹니다.
메모 카드의 출처 누르기PDF 가 그 자리로 갑니다. 카드 메뉴의 「원문에서 보기」도 같고, 「형광펜과 메모 지우기」로 지웁니다.

색 고르기

「형광펜」 도구는 메모 없이 색만 칠합니다. 기본 색은 아래 네 가지이고, 설정의 「화면 및 문서 → 형광펜 색」에서 이름을 붙여 최대 8가지까지 더하고 끌어서 순서를 바꿀 수 있습니다. 색을 지워도 그 색으로 칠한 형광펜은 「기타」 색으로 남습니다.

이어진 선

노트 바는 창 오른쪽 끝에 고정되어 있어서, 칸이 여럿이어도 연결선이 다른 칸을 가로질러 카드에 닿습니다. 선은 형광펜과 같은 색입니다. 도구줄의 눈 모양 단추 「표시 모두 감추기」는 형광펜, 메모, 선을 한꺼번에 숨겨 줍니다. 되돌리기(Ctrl+Z)는 형광펜, 그림, 메모 노트의 변경을 되돌리되 다른 창에서 더한 것은 건드리지 않습니다.

해 보기 2
  1. 「형광펜」 도구로 바꾸고 색을 하나 골라 문장 몇 개를 칠해 봅니다.
  2. 칠한 문장을 눌러 노트의 카드가 열리는 것을 보고, 카드 메뉴의 「형광펜과 메모 지우기」로 지워 봅니다. 눈 모양 단추로 표시를 숨겼다 다시 보입니다.

캡처 · 박스 메모 · 그리기

글이 아닌 것, 곧 표와 그림은 영역 캡처로 담고, 쪽 위에는 직접 쓰고 그립니다.

영역 캡처

도구줄의 「영역 캡처」로 표나 그림을 네모로 감싸면, 노트에 그림이 설명 칸과 함께 들어갑니다. 잡아 둔 네모는 변과 모서리를 끌어 크기를 바꿀 수 있습니다. Ctrl 을 누른 채 끌어도 표와 그림을 감쌀 수 있습니다. 글자 없는 스캔 쪽에서 영역을 잡으면 OCR 로 읽은 글자도 함께 붙습니다.

박스 메모와 그리기

「박스 메모」는 쪽 여백에 메모 상자를 붙이고 선으로 잇습니다. 「글 상자」, 「펜」과 그리기 도구(선, 화살표, 네모, 동그라미), 「지우개」는 PDF 위에 직접 씁니다. 떠 있는 서식 창에서 색과 굵기를 고릅니다. 지우개는 그림뿐 아니라 형광펜과 박스 메모도 지웁니다.

한 글자 단축키T 글 상자 · P 펜 · L 선 · A 화살표 · R 네모 · O 동그라미 · X 가리기 · E 지우개 · Esc 도구 끄기 (글 쓰는 칸 밖에서)
그리기 연습 칸: 여기에 펜으로 그리고, 글 상자를 놓고, 박스 메모를 붙여 보세요
해 보기
  1. 「영역 캡처」를 켜고 위의 그림 1 을 네모로 감쌉니다. 노트에 그림이 들어가면 설명을 적어 보세요.
  2. 네모의 변이나 모서리를 끌어 크기를 바꿔 봅니다.
  3. 「박스 메모」로 여백에 상자를 붙이고, P 를 눌러 연습 칸에 그린 뒤 E 로 지웁니다. Esc 로 도구를 끕니다.

소제목아래 블록을 묶습니다. 접으면 숨고, 끌면 묶인 블록이 함께 옮겨집니다.
글노트에 직접 쓰는 글입니다. 굵게, 목록, 표, 코드를 쓸 수 있습니다.
메모내 글 아래에 출처(쪽 번호)가 붙습니다. 출처를 누르면 PDF 의 그 자리로 갑니다. 출처를 여럿(캡처 포함) 붙일 수 있습니다.
티켓ID 와 제목이 붙은 메모입니다. 요구사항을 챙길 때 씁니다.

블록의 왼쪽 손잡이를 잡고 끌면 순서를 바꿀 수 있습니다. Ctrl 또는 Shift 를 누르고 여러 블록을 골라 한꺼번에 끌 수도 있습니다.

ID 와 제목 (티켓)

메모에는 ID 와 제목을 붙일 수 있습니다. 메모에 마우스를 올리면 오른쪽 위에 「+ ID」 「+ 제목」이 보이고, 메모 맨 앞에 REQ-04 처럼 써도 ID 가 됩니다. 다음 번호를 제안하고, 노트에 이미 있는 ID 면 알려 줍니다.

아래는 연습용 요구사항입니다. 한 줄씩 칠해 메모를 만들고 ID 를 붙여 보세요.

REQ-01 저장한 노트는 앱을 다시 켜도 그대로 남아야 한다.
REQ-02 형광펜을 지우면 그 메모 블록도 노트에서 빠져야 한다.
REQ-03 쪽 순서를 바꿔도 형광펜은 같은 글을 가리켜야 한다.
REQ-04 번역할 글은 사용자가 고른 곳으로만 보내야 한다.

이 Vault 의 예시 노트에는 REQ-01 과 REQ-03 이 이미 티켓으로 들어 있습니다.

왼쪽 바 · 라이브러리 · 버전

왼쪽 바 위의 다섯 탭이 문서를 찾고 훑는 길입니다.

탐색기Vault 의 문서와 노트 목록. 지금 열린 문서에 점이 붙고, 선택된 문서와 노트가 표시됩니다.
목록이 PDF 의 목차와 책갈피. 누르면 그 쪽으로 갑니다.
미리보기쪽 썸네일. 지금 화면에 보이는 영역이 사각형으로 표시됩니다.
PDF 도구OCR, 비교, 합치기 같은 도구 모음 (9쪽).
검색「이 문서」와 「모든 문서」를 오가며 찾습니다. 대소문자 구분(Aa)과 단어 단위(W) 옵션이 있고, 결과를 누르면 그 자리에서 열립니다.

모든 문서 검색은 파일 이름, 폴더, PDF 본문, Markdown 내용을 한곳에서 찾습니다. 글자 층이 없는 쪽은 PC 안에서 OCR 로 읽어 색인합니다.

라이브러리 펼치기

왼쪽 바 위쪽의 「라이브러리 펼치기」(Ctrl+Shift+L)를 누르면 왼쪽 바가 전체 · 즐겨찾기 · 최근 열람 · 폴더 탐색으로 바뀌고, 오른쪽이 모든 문서의 표가 됩니다.

  • 제목, 저자, 연도 같은 논문 정보를 그 자리에서 고치고, 정렬하고, 별표를 달고, 모음으로 묶습니다. 목록과 카드 보기를 오갑니다.
  • 논문 정보는 PDF 나 Crossref 에서 채우고, BibTeX 인용 정보를 복사할 수 있습니다.

버전 묶음

같은 문서의 초안, 수정본, 최종본을 한 문서의 버전으로 묶어 오갑니다. 파일 행의 메뉴에서 「다른 파일과 버전으로 묶기…」를 고르면 되고, 묶음을 풀어도 파일은 그대로입니다. PDF 도구의 「다른 버전과 글자 비교」(9쪽)가 두 버전에서 바뀐 곳만 나란히 보여 줍니다.

따로 확대하기

왼쪽 바, 오른쪽 노트 바, 라이브러리 위에서 Ctrl+휠을 돌리면 각각 80~150% 안에서 따로 확대됩니다. 값은 앱에 저장되고, PDF 의 확대와 서로 영향을 주지 않습니다. 앱 전체 글자 크기는 설정의 「화면 크기」에서 바꿉니다.

해 보기
  1. 「목록」에서 목차 항목을 눌러 장으로 이동하고, 「미리보기」에서 사각형이 따라 움직이는 것을 봅니다.
  2. Ctrl+Shift+F 를 눌러 「모든 문서」에서 Vault 를 찾고, 결과를 눌러 이동합니다.
  3. Ctrl+Shift+L 로 라이브러리를 펼쳤다 접습니다. 왼쪽 바 위에서 Ctrl+휠도 돌려 보세요.

번역과 Markdown

원문은 그대로 두고, 고른 글만 번역해서 곁에 펼칩니다.

번역

글을 고르면 나타나는 단추 중 「번역」을 누르면 결과 카드가 뜹니다. 카드에는 언어, 번역 방식, 다시 시도, 원문과 함께 복사가 있습니다. 노트의 출처 줄마다 작은 번역 단추가 있어서 누르면 바로 아래에 번역이 펼쳐집니다. 줄바꿈으로 끊긴 글은 이어 붙여 번역하고, 이미 대상 언어인 글은 다른 언어로 번역합니다.

방식특징
로컬 (Ollama)내 PC 에서 번역합니다. 글이 PC 밖으로 나가지 않습니다. 모델 크기에 따라 느릴 수 있습니다.
클라우드OpenAI, Anthropic, Gemini, Azure Translator, DeepL 중에서 고릅니다. 고른 글이 그 서비스로 전송됩니다.

연습 4클라우드 API 키는 이 PC 의 자격 증명 저장소에 보관됩니다.

번역 캐시: 한 번 번역한 글을 같은 언어로 다시 번역하면 요청 없이 바로 꺼내 씁니다. 설정의 「번역」에서 끄거나 지울 수 있고, 번역은 Vault 의 .iwae 안에만 남습니다. 방식과 API 키도 같은 곳에서 고릅니다.

Markdown 문서

Markdown 문서도 PDF 옆 탭으로 열리고, 제목, 표, 코드, 할 일 목록과 목차를 보여 줍니다. 글을 골라 형광펜과 메모를 달고 영역 캡처를 하는 방법은 PDF 와 똑같고, 메모는 같은 노트에 섞입니다. 모양은 설정의 「Markdown 문서 테마」에서 바꿉니다 (원본 파일은 바뀌지 않습니다).

  • GitHub 에서 가져오기: 왼쪽 「탐색기」 위의 GitHub 단추로 저장소의 Markdown 문서 폴더를 가져옵니다. 새 커밋이 있으면 상단바가 알려 주고, 최신으로 받거나 브랜치, 태그, 커밋의 예전 버전으로 바꿔 볼 수 있습니다.
해 보기
  1. 위의 연습 5 영어 문단을 끌어 골라 「번역」을 누릅니다. 같은 문단을 한 번 더 번역하면 캐시 덕분에 바로 나옵니다.
  2. 그 글을 메모로 칠해 두고, 노트 카드의 출처 줄에 있는 번역 단추를 눌러 봅니다.
  3. Markdown 예시 탭에서 문장 하나를 칠해 같은 노트에 메모를 만듭니다.
