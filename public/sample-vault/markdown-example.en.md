# Markdown example

IWAE reads and marks up **Markdown** documents as well as PDFs. You can select text here, highlight it and add memos just like in a PDF.

## Try it

1. Drag over the sentence below. A highlight is painted and a memo opens in the note. If no note is visible, press Ctrl+Shift+M to open one beside the document.
2. Write a memo, scroll away, then click the memo card. This document returns to that sentence.

> Memos you add to a Markdown document go into the same note as memos from PDFs.

## Formatting

- **Bold**, *italic*, `code`
- [ ] A to-do item
- [x] A finished item

> Quotes look like this.

## Tables

| Document | Good for |
| --- | --- |
| PDF | Papers, books, standards, manuals |
| Markdown | Your own writing, READMEs, meeting notes |
| Note | Memos from many documents in one place |

You can also box a table or figure with “Region capture” to put it in the note as an image.

## Code

```json
{
  "name": "IWAE",
  "notes": ["memo", "ticket", "text"]
}
```

## Outline and links

The “Outline” tab in the left bar lists this document's headings. You can link to other documents in the same Vault: [IWAE User Guide](IWAE%20User%20Guide.pdf)
