# Markdown example

IWAE reads and marks up **Markdown** documents as well as PDFs. You can select text here, highlight it and add memos just like in a PDF.

## Formatting

- **Bold**, *italic*, `code`
- [ ] A to-do item
- [x] A finished item

> Quotes look like this.

## Tables

| Document | Good for |
| --- | --- |
| PDF | Papers, books, standards, manuals |
| Markdown | Your own writing, READMEs, meeting notes |
| Note | Memos from many documents in one place |

## Code

```json
{
  "name": "IWAE",
  "notes": ["memo", "ticket", "text"]
}
```
