# Markdown 예시

IWAE 는 PDF 와 함께 **Markdown** 문서도 읽고 표시합니다. 이 글에서도 PDF 처럼 글을 골라 형광펜을 칠하고 메모를 달 수 있습니다.

## 서식

- **굵게**, *기울임*, `코드`
- [ ] 할 일 목록
- [x] 끝낸 일

> 인용문은 이렇게 보입니다.

## 표

| 문서 | 쓰임 |
| --- | --- |
| PDF | 논문, 책, 표준, 설명서 |
| Markdown | 내가 쓴 글, README, 회의록 |
| 노트 | 여러 문서의 메모를 한곳에 |

## 코드

```json
{
  "name": "IWAE",
  "notes": ["메모", "티켓", "글"]
}
```
