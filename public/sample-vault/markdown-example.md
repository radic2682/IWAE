# Markdown 예시

IWAE는 PDF와 함께 **Markdown** 문서도 읽고 표시합니다. 이 글에서도 PDF처럼 글을 골라 형광펜을 칠하고 메모를 달 수 있습니다.

## 해 보기

1. 아래 문장을 끌어서 고르면 형광펜이 칠해지고 노트에 메모 칸이 열립니다. 노트가 보이지 않으면 Ctrl+Shift+M으로 문서 옆에 엽니다.
2. 메모를 쓴 뒤 다른 곳으로 내려갔다가 메모 카드를 눌러 보세요. 이 글이 그 문장으로 돌아옵니다.

> Markdown 문서에 단 메모도 PDF에 단 메모와 같은 노트에 들어갑니다.

## 서식

- **굵게**, *기울임*, `코드`
- [ ] 할 일 목록
- [x] 끝낸 일

> 인용문은 이렇게 보입니다.

## 표

| 문서 | 쓰임 |
| --- | --- |
| PDF | 논문, 책, 표준, 설명서 |
| Markdown | 내가 쓴 글, README, 회의록 |
| 노트 | 여러 문서의 메모를 한곳에 |

표나 그림은 「영역 캡처」로 감싸 노트에 그림으로 넣을 수도 있습니다.

## 코드

```json
{
  "name": "IWAE",
  "notes": ["메모", "티켓", "글"]
}
```
